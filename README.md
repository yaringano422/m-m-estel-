# Sistema de Facturación Gastronómica - Recreo Turistico Mama Estelita - Chupaca - Junin - Peru

Software de gestión operativa diseñado para automatizar el flujo de trabajo en restaurante de comida típica, desde la recepción del pedido hasta la facturación final.

## 🛠️ Soluciones Implementadas
* **Gestión de Comandas:** Flujo optimizado para la toma de pedidos y envío a cocina.
* **Facturación:** Generación de comprobantes y cierre de caja diario.
* **Base de Datos:** Estructura optimizada para el manejo de menús dinámicos e inventario de insumos.

## 🚀 Impacto
El sistema reduce los errores manuales en la facturación y centraliza la información financiera del establecimiento para una mejor toma de decisiones.

## 🛠️ Tecnologías
* **Base de Datos:** PostgreSQL (Supabase).
* **Entorno:** [web}.
* **Hosting:** Vercel
